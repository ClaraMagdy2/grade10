# Grade 10 Smart Hospital Assistant Website

United International School — Grade 10 Computer Science — Quarter 1.

## Files
- index.html — complete responsive website
- assets/uis-logo.png — supplied school logo

## How to use
1. Keep `index.html` and the `assets` folder together.
2. Open `index.html` in a browser.
3. Use the navigation to view the layers, standards, Python code, tests, and debugging section.
4. The test panels mirror the Python logic in JavaScript so students can interact with the examples directly in the browser.

## GitHub Pages
Upload the whole folder to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from branch.
