03 • Python Code 01

Patient Information & Temperature Check

The first program collects patient data and uses conditions to classify the temperature.

smart_hospital_01.py
doctors = [
    "Dr. Ahmed - Cardiology",
    "Dr. Sara - Pediatrics",
    "Dr. Omar - General Medicine",
    "Dr. Mona - Dermatology"
]

print("================================")
print("     SMART HOSPITAL ASSISTANT")
print("================================")

name = input("Enter patient name: ")
age = int(input("Enter patient age: "))
temperature = float(input("Enter body temperature: "))

print("\nPatient:", name)
print("Age:", age)

# Temperature check
if temperature >= 38:
    print("Status: High temperature")
elif temperature >= 37:
    print("Status: Slightly elevated")
else:
    print("Status: Normal")

04 • Python Code 02

Menu, Doctors & Appointment Booking

The second program adds a loop so the user can repeatedly view doctors, check temperature, book an appointment or exit.

smart_hospital_02.py
while True:
    print("\n========== MENU ==========")
    print("1. View Doctors")
    print("2. Check Temperature")
    print("3. Book Appointment")
    print("4. Exit")

    choice = input("Choose an option: ")

    if choice == "1":
        print("\nAvailable Doctors:")

        for doctor in doctors:
            print("-", doctor)

    elif choice == "2":
        temperature = float(input("Enter new temperature: "))

        if temperature >= 38:
            print("High temperature. Please consult a doctor.")
        elif temperature >= 37:
            print("Slightly elevated temperature.")
        else:
            print("Temperature is normal.")

    elif choice == "3":
        print("\nChoose a doctor:")

        for i in range(len(doctors)):
            print(i + 1, doctors[i])

        doctor_choice = int(input("Enter doctor number: "))

        if doctor_choice >= 1 and doctor_choice <= len(doctors):
            print("Appointment booked with",
                  doctors[doctor_choice - 1])
        else:
            print("Invalid doctor number.")

    elif choice == "4":
        print("Thank you for using Smart Hospital Assistant!")
        break

    else:
        print("Invalid choice. Please try again.")

05 • Troubleshooting

Debugging & Testing

Debugging means finding the cause of an error, correcting it, and testing again to make sure the program behaves as expected.

Common errors to check

  • Using the wrong data type, such as forgetting int() for age.
  • Incorrect indentation inside if, elif, else, for, or while.
  • Using an invalid doctor number that is outside the list range.
  • Forgetting to use break when the user chooses Exit.

Example debugging task

# Buggy condition if temperature > 38: print("High temperature") elif temperature > 37: print("Slightly elevated") # Question: # What happens when temperature is exactly 38?

Think: Compare the condition with the intended boundary. Test 38, 37 and 36.5 to verify the behavior.
