Abstraction in Everyday Technology

Objectives
  1. Define abstraction.
  2. Identify abstraction in technology.
  3. Explain hidden details.
  4. Apply abstraction to examples.
Standard

Explain how abstractions hide the underlying implementation details of computing systems embedded in everyday objects.

Assessment & Activities

Students use a short research paper/search task. They identify what a user sees and what the computer hides.

Resources

Research paper • Search • Abstraction examples

Explanation

Abstraction means showing the important features of a system while hiding unnecessary implementation details. When you tap “Send” in a messaging app, you do not need to know how packets, servers, encryption and network routing work. The interface gives you a useful high-level view.

In computing, abstraction reduces complexity. A user can operate a camera without understanding image sensors. A programmer can use print() without knowing every operating-system instruction used to display characters.

Think → Identify → Explain: Pick an ATM, smartphone, microwave or hospital scanner. What does the user control? What technical details are hidden?
Exit Ticket

1) Define abstraction in one sentence. 2) Give one everyday example. 3) Name one implementation detail hidden from the user.

Hardware, Software & OS Layers

Objectives
  1. Identify hardware and software.
  2. Define the operating system.
  3. Explain system layers.
Standard

Compare levels of abstraction and interactions between application software, system software, and hardware layers.

Assessment & Activities

Divide students into 3 groups with worksheets. Each group maps a computing task across layers.

Resources

Search • Hardware examples • Software examples • Worksheets

Explanation

Hardware is the physical part of a computer: CPU, RAM, storage, keyboard, screen and sensors. Software is the set of instructions and programs that tell hardware what to do.

The operating system (OS) is system software that manages hardware resources and provides services for applications. Examples include Windows, Linux, macOS, Android and iOS.

System SoftwareOperating SystemManages memory, files, devices and processes
HardwareCPU • RAM • Storage • KeyboardPhysical components that perform and store work

Python Variables, Data Types & Lists

Objectives
  1. Define variables.
  2. Identify data types.
  3. Create Python lists.
  4. Use variables in programs.
Standard

Use lists to simplify solutions, generalizing computational problems instead of repeatedly using simple variables.

Assessment & Activities

Divide students into 3 groups with worksheets. Students search for data-structure examples and model hospital data.

Resources

Search • Python data structures • Worksheets

Explanation

A variable is a named reference to a value. Common Python data types include str (text), int (whole number), float (decimal), and bool (True/False). A list stores multiple ordered values in one structure.

patient_name = "Mona"
age = 42
temperature = 37.2
has_allergy = False

symptoms = ["fever", "cough", "fatigue"]

Lists are useful when a hospital system has many patients, symptoms, medicines or appointments. Instead of creating separate variables for every item, one list can hold related values.

Python Control Structures: Conditions & Loops

Objectives
  1. Explain conditions.
  2. Use if / elif / else.
  3. Use for and while loops.
  4. Solve problems using control structures.
Standard

Justify the selection of specific control structures when tradeoffs involve implementation, readability, and program performance, and explain the benefits and drawbacks of choices made.

Assessment & Activities

Divide students into 3 groups with worksheets. Students search for loop examples and compare condition choices.

Resources

Search • Loops • Worksheets • Programiz

Explanation

Conditions allow a program to make decisions. if runs code when a condition is true; elif checks another condition; else provides a fallback. A for loop is useful for processing each item in a collection. A while loop repeats while a condition remains true.

temperature = 39.1

if temperature >= 39:
    print("High temperature")
elif temperature >= 37.5:
    print("Raised temperature")
else:
    print("Normal range")

patients = ["Ali", "Mona", "Omar"]
for patient in patients:
    print(patient)

Control structures should be selected for clarity and suitability. A loop can prevent repetitive code, while a clear condition can make a decision easy to read and test.

Exit Ticket

Write one situation where an if statement is appropriate and one where a for loop is appropriate. Explain why.

  2. Debug Python code.
  3. Test and fix programs.

Standard

Assessment & Activities

Divide students into 3 groups with worksheets. Students find bugs, predict the error, test a fix and explain the solution.

Resources

Explanation

Debugging is the systematic process of finding and fixing problems in a program. Common errors include SyntaxError (invalid Python grammar), NameError (using an undefined name), TypeError (an operation uses an inappropriate type) and logical errors (the program runs but produces the wrong result).

1ReproduceMake the error happen again.2ReadInspect the message and line.3IsolateFind the smallest faulty part.4FixChange one thing at a time.5TestCheck normal and edge cases.

PYTHON PROJECT

Starter Python Prototype

Students can paste this into Programiz and extend it.

patients = []

def add_patient():
    name = input("Patient name: ")
    age = int(input("Age: "))
    patient_id = input("Patient ID: ")
    symptoms = input("Symptoms (comma separated): ").split(",")

    patient = {
        "name": name,
        "age": age,
        "id": patient_id,
        "symptoms": symptoms
    }
    patients.append(patient)
    print("Patient added.")

def show_patients():
    if not patients:
        print("No patients registered.")
        return

    for patient in patients:
        print(patient["id"], "-", patient["name"])

add_patient()
show_patients()
